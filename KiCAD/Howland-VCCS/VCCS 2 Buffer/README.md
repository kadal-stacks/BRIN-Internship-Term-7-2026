# VCCS 2 Buffer

Folder ini merupakan workspace terpisah untuk pengembangan blok buffer pada rangkaian VCCS.

- [Howland-VCCS-2-Buffer](Howland-VCCS-2-Buffer/README.md): schematic buffer berbasis AD826ANZ dan dua TL082.

Pada tree repository saat ini belum tersedia PCB layout yang terisi, Gerber, atau gambar area board. Dokumentasikan fungsi buffer, nilai resistor, supply, dan hasil simulasi setelah desain diperbarui.
