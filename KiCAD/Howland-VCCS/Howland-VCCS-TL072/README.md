# Howland VCCS with TL072

Berisi project KiCad untuk rangkaian Howland VCCS berbasis op-amp TL072: file .kicad_pro, .kicad_sch, dan .kicad_pcb.

Periksa rasio resistor, koneksi input, pin suplai TL072, terminal beban, dan polaritas konektor. Jalankan ERC/DRC lalu simulasikan respons input dan beban. TL072 bukan op-amp rail-to-rail, jadi pastikan rentang input/output sesuai datasheet. File .kicad_prl merupakan setelan sesi lokal, bukan sumber desain utama.
