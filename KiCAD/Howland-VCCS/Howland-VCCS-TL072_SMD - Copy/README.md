## Catatan komponen
Varian ini memiliki daftar resistor 100 kΩ (R1/R3), 20 kΩ (R2/R4), 100 Ω (R5), dua resistor generic (R6/R7), dua kapasitor generic (C1/C2), dua solder jumper, mounting hole, dua header 1×3 dan TL072. Nilai R6/R7 dan C1/C2 belum lengkap.

Periksa juga footprint U1: schematic mencatat DIP-8 meski folder menyebut SMD. Sebelum konsolidasi salinan, bandingkan file schematic/PCB dan pilih satu pasangan project/board yang benar.
