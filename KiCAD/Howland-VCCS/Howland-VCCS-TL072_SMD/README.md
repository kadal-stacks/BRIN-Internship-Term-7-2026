# Howland VCCS with TL072 (SMD / Hybrid)

Folder ini adalah induk varian dengan resistor SMD. File project, Gerber, dan gambar area berada di subfolder [Howland-VCCS-TL072_SMD](Howland-VCCS-TL072_SMD/README.md).

![Howland VCCS SMD board area](Howland-VCCS-TL072_SMD/VCCS%20PCB%20Area.png)

**Dimensi outline:** 27.078 mm × 22.886 mm, radius sudut 1 mm. Luas rounded outline **618.85 mm² (6.1885 cm²)**.

Catatan: varian ini merupakan desain hybrid, bukan full-SMD. Schematic terbaru mencatat U1 TL072 dengan footprint DIP-8, RV1 1 kΩ dengan footprint trimmer THT, konektor J4 1×6 THT, empat resistor 100 kΩ SMD 0805, serta R5 150 Ω SMD 0805.
