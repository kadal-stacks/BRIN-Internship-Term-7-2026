# Howland VCCS with TL072 (SMD)

Folder parent untuk jalur varian SMD. Project KiCad berada di subfolder [Howland-VCCS-TL072_SMD](Howland-VCCS-TL072_SMD/README.md).

Karena parent dan folder nested memiliki nama serupa, buka file .kicad_pro di folder terdalam. Bandingkan file dan commit jika memilih antara revisi mirip. Sebelum merapikan duplikat, pastikan tidak ada schematic, PCB, atau konfigurasi yang hanya ada di salah satu folder.
