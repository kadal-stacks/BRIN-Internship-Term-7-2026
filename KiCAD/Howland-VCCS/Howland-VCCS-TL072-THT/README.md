# Howland VCCS with TL072 (THT)

Varian THT rangkaian Howland VCCS berbasis TL072. File utama adalah project .kicad_pro, schematic .kicad_sch, dan layout .kicad_pcb.

Validasi pin op-amp dan nilai komponen, sinkronkan schematic ke PCB, lalu jalankan ERC/DRC. Pastikan diameter drill, annular ring, pitch, footprint, dan jarak ke edge sesuai komponen fisik. Tinjau catu daya TL072, arah konektor, dan batas tegangan beban. Layout yang lolos DRC tetap perlu pengujian akurasi dan kestabilan.
