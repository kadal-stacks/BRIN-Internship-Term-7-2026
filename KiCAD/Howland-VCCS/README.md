# Howland Voltage-Controlled Current Source (VCCS)

Folder ini berisi beberapa revisi rangkaian Howland VCCS menggunakan TL072.
- [TL072](Howland-VCCS-TL072/README.md)
- [TL072 THT](Howland-VCCS-TL072-THT/README.md)
- [TL072 SMD](Howland-VCCS-TL072_SMD/README.md)
- [TL072 SMD copy](Howland-VCCS-TL072_SMD%20-%20Copy/README.md)

Periksa nilai/toleransi resistor, konfigurasi TL072, common-mode dan output swing, catu daya, terminal beban, serta target arus. ERC/DRC tidak membuktikan kestabilan loop atau akurasi output. Catat target arus, compliance voltage, beban uji, dan hasil simulasi/pengukuran bila tersedia. Bandingkan revisi sebelum menetapkan versi kanonis.
