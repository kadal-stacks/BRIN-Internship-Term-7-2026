# KiCad Projects

Folder ini mengelompokkan desain elektronik, schematic, PCB layout, dan library komponen.

## Proyek
- [ATMega16-STM32 BP Adapter](ATMega16-STM32%20BP%20Adapter/README.md): adapter SMD dan THT.
- [Howland-VCCS](Howland-VCCS/README.md): rangkaian sumber arus berbasis TL072 dengan beberapa varian.
- [Impedance-meter2D_Main Board](Impedance-meter2D_Main%20Board/README.md): workspace main board impedance meter.
- [Part Lib](Part%20Lib/README.md): library simbol, footprint, dan model komponen.

## Workflow
Buka file project .kicad_pro, tinjau schematic dan footprint, jalankan ERC/DRC, periksa mekanik/konektor, lalu validasi hasil ekspor sebelum fabrikasi. Folder salinan dipertahankan sesuai Git; bandingkan file dan commit sebelum memilih versi kanonis.
