# ATmega16–STM32 Adapter (THT)

Varian through-hole technology (THT) untuk adapter ATmega16–STM32. Project utama, schematic, dan PCB masing-masing tersedia sebagai file .kicad_pro, .kicad_sch, dan .kicad_pcb.

Buka file project, cocokkan konektor/header termasuk orientasi pin 1, dan periksa mapping ATmega16–STM32. Jalankan ERC/DRC dan verifikasi diameter drill, annular ring, pitch, serta jarak ke edge board. Jangan menganggap versi THT setara secara mekanik dengan SMD tanpa pengukuran komponen fisik.
