# Impedance Meter – Main Board

Folder ini dimaksudkan untuk project main board impedance meter.

## Status yang bisa diverifikasi
Pada tree repository yang diperiksa hanya ada <code>Impedance-meter2D_Main Board.kicad_pro</code> dan file sesi <code>.kicad_prl</code>. File schematic <code>.kicad_sch</code> serta PCB <code>.kicad_pcb</code> belum tersedia pada folder ini.

Karena schematic dan board belum ada, **BOM, fungsi setiap blok rangkaian, dan gambar layout aktual belum dapat ditentukan dengan aman**. README ini sengaja tidak menempelkan foto perangkat generik seolah-olah itu hasil proyek.

## Langkah berikutnya
1. Tambahkan/restore file schematic dan PCB yang sesuai ke folder ini.
2. Setelah schematic ada, dokumentasikan blok pengukuran impedansi, generator sinyal, front-end analog, ADC/MCU, serta konektor sesuai komponen yang benar-benar digunakan.
3. Sertakan gambar screenshot schematic/PCB dari KiCad (bukan ilustrasi AI), daftar komponen dari BOM, versi software, dan status ERC/DRC.
