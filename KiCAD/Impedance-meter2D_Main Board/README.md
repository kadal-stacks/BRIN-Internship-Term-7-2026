# Impedance Meter – Main Board

Folder ini dimaksudkan sebagai workspace project main board impedance meter.

Pada tree repository yang diperiksa, baru terlihat file .kicad_pro dan .kicad_prl; belum terlihat schematic .kicad_sch atau PCB .kicad_pcb. Anggap project belum lengkap sampai file desain utama tersimpan di Git.

Buka project dan periksa apakah file terkait masih lokal atau belum ditambahkan. Jika desain belum dibuat, mulai dari schematic, beri label net konsisten, lalu buat PCB. Tambahkan instruksi fabrikasi serta status pengujian setelah file tersedia.
