# STM32 Footprints

Berisi footprint KiCad untuk modul STM32 Blue Pill, Black Pill, dan beberapa varian WeAct Black Pill. Varian membedakan gaya silkscreen dan koneksi debug SWD.

Pilih berdasarkan modul/header/konektor yang benar-benar digunakan. Tambahkan melalui Preferences → Manage Footprint Libraries, lalu cocokkan nickname library, nomor pad, pitch, orientasi USB, outline board, dan clearance. Preview tersedia pada folder [images](../images/README.md).
