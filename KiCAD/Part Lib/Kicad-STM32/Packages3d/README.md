# 3D Package Models

Folder ini menyimpan arsip ZIP model 3D untuk varian Blue Pill/Black Pill. Nama arsip membedakan konfigurasi header/soket dan konektor/breakout SWD; files.txt berisi daftar pendamping.

Pilih model yang cocok, ekstrak ke lokasi stabil, atur path model pada library KiCad, lalu periksa alignment via 3D Viewer. Model 3D membantu cek mekanik, tetapi bukan pengganti pengukuran modul fisik.
