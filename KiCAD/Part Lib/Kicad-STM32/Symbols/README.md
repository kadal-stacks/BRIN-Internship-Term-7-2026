# STM32 Symbols

Berisi simbol Blue Pill dan Black Pill, termasuk varian part-like dan opsi breakout SWD. File .lib/.dcm adalah format library simbol legacy KiCad pada kumpulan ini.

Tambahkan lewat Preferences → Manage Symbol Libraries. Cocokkan nomor/nama pin terhadap datasheet MCU/modul, termasuk suplai, ground, ADC, timer/PWM, UART, SPI, I2C, reset, oscillator, dan SWD. Jika mengonversi format, lakukan pada salinan dan pastikan project lama tetap membuka simbol.
