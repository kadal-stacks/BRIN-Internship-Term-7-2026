# Library Preview Images

Folder ini memuat gambar referensi library, termasuk foto modul Blue Pill/Black Pill dan preview simbol/footprint. Gunakan untuk mengenali bentuk, orientasi konektor, opsi footprint, dan breakout SWD.

Untuk nomor pin, fungsi listrik, dan dimensi, datasheet serta file library tetap menjadi acuan. Preview bukan bukti bahwa footprint telah diuji atau difabrikasi.
