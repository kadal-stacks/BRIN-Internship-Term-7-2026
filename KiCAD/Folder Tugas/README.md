# KiCad Task Folder

Folder ini disediakan untuk materi latihan/tugas KiCad. Pada tree repository saat ini belum terlihat file desain utama yang dapat diidentifikasi di sini.

Simpan tiap tugas dalam subfolder jika terdiri dari beberapa file. Sertakan project .kicad_pro, schematic .kicad_sch, PCB .kicad_pcb bila ada, serta catatan tujuan, sumber komponen, dan status verifikasi.
