# Source Code

Source utama main.cpp memuat rutinitas TWI/I2C level-register pada ATmega328P untuk komunikasi BMP280, dengan alamat yang didefinisikan sebagai 0x76.

Nama folder induk adalah ADC Test, tetapi source yang ada lebih berfokus pada komunikasi I2C sensor. Tinjau keseluruhan implementasi sebelum menyimpulkan pembacaan ADC sudah diterapkan. Build dari root project menggunakan pio run -e nanoatmega328.
