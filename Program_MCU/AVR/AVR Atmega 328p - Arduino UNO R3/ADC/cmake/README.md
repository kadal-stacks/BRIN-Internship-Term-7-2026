# CMake Toolchain

Folder ini menyimpan avr-gcc.toolchain.cmake untuk cross-compilation menuju AVR. Pastikan avr-gcc, avr-g++, avr-libc, CMake, dan tool upload tersedia di PATH. Cocokkan MCU, clock, programmer, dan port dengan board target. Konfigurasi utama berada di CMakeLists.txt.
