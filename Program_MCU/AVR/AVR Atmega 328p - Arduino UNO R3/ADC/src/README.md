# Source Code

Folder ini memuat main.cpp sebagai entry point aplikasi bare-metal C/C++ dari template AVR CMake. Pada tree yang diperiksa, file ini masih ringkas; tinjau implementasinya sebelum menyimpulkan fungsi ADC atau peripheral lainnya sudah lengkap.

Konfigurasi build berada di CMakeLists.txt pada root project. Pastikan clock, compiler AVR, programmer, dan port sesuai hardware.
