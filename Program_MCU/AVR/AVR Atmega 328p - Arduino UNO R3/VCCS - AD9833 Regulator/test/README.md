# Test Directory

Direktori untuk test firmware atau prosedur uji hardware. Belum ada test otomatis yang teridentifikasi.

Pengujian yang disarankan: validasi SPI Mode 2 dan FSYNC, frekuensi startup 1 kHz, rentang 10 Hz–10 kHz, serta penanganan input serial invalid/out-of-range. Ukur keluaran DDS dengan frequency counter atau osiloskop.
