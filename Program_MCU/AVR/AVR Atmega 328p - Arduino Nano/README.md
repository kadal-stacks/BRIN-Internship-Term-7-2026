# ATmega328P – Arduino Nano

Folder ini berisi proyek firmware untuk ATmega328P dengan konfigurasi PlatformIO.

## Proyek

- [VCCS–AD9833 Regulator](VCCS-AD9833%20Regulator/README.md): firmware SPI untuk mengatur frekuensi keluaran DDS AD9833 melalui Serial Monitor.

Periksa `platformio.ini` dalam tiap proyek untuk target board/bootloader yang dipakai.
