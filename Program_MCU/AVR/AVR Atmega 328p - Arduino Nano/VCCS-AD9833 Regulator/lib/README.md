# Project Libraries

Direktori untuk pustaka lokal khusus project. Source yang sekarang menggunakan Arduino core dan register AVR secara langsung; belum ada library lokal yang teridentifikasi sebagai dependency.

Jika menambahkan library AD9833 atau komponen lain, catat sumber, versi, lisensi, dan alasan pemakaian. Jangan menyimpan salinan library eksternal tanpa dokumentasi.
