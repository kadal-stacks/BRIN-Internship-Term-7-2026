# Test Directory

Direktori untuk unit test atau prosedur pengujian hardware. Belum ada test otomatis yang teridentifikasi pada folder ini.

Pengujian yang relevan:
- Verifikasi SPI Mode 2 dan pulsa FSYNC dengan logic analyzer.
- Periksa keluaran 1 kHz saat startup.
- Uji frekuensi batas 10 Hz dan 10 kHz serta beberapa nilai tengah.
- Bandingkan frekuensi keluaran dengan frequency counter/osiloskop.
- Uji input serial invalid, di luar rentang, dan terlalu panjang.
