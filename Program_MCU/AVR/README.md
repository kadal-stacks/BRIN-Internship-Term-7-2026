# AVR Projects

Folder ini menampung proyek berbasis keluarga mikrokontroler AVR.

- [ATmega328P – Arduino Uno R3](AVR%20Atmega%20328p%20-%20Arduino%20UNO%20R3/README.md): eksperimen ADC/BMP280, LED non-blocking, dan satu salinan program kontrol AD9833.
- [ATmega328P – Arduino Nano](AVR%20Atmega%20328p%20-%20Arduino%20Nano/README.md): program kontrol frekuensi AD9833 untuk rangkaian VCCS.

Baca konfigurasi PlatformIO masing-masing proyek sebelum build. Nama folder tidak selalu sama dengan nilai `board` yang tercantum di `platformio.ini`.
