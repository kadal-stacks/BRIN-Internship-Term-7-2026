# Microcontroller Firmware

Folder ini mengelompokkan source code dan eksperimen mikrokontroler, terutama proyek AVR ATmega328P/Arduino Uno atau Nano.

- [AVR](AVR/README.md): proyek keluarga mikrokontroler AVR.

Sebelum build, baca platformio.ini atau CMakeLists.txt agar board, clock, framework, dan toolchain tidak tertukar. Periksa konflik pin UART/I2C/SPI/ADC/timer, build dulu lalu upload dengan port yang benar, dan catat hasil uji hardware.
